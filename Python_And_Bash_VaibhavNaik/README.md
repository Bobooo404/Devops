# Python and Bash Calculator

## Description

This project is a menu-driven calculator developed using Python and Bash.

The Python program performs addition, subtraction, multiplication, and division.

The Bash scripts are used to run the calculator and automate basic testing.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Invalid input handling
- Menu-driven interface
- Repeated execution using a loop
- Bash wrapper script
- Automated testing using Bash

## Requirements

- Python 3
- Bash

## How to Run

Run the Python calculator:

```bash
python3 calculator.py
